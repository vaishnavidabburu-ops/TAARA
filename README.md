# TAARA — Heatwave Early Warning & Human Thermal Stress Platform
SIH 2026 | Problem Statement 26083

## Run
npm install
npm run dev

## Build
npm run build

## Live data
The prototype requests current weather from Open-Meteo for selected Andhra Pradesh locations. No API key is required. Heat-risk calculations are a demo decision-support model, not a scientifically validated forecast.

## Important
This version contains **heatwave / thermal-stress simulation only**. Flood and river simulation have been removed.

## Deploy to GitHub + Vercel
1. Create a GitHub repository.
2. Upload the contents of this folder.
3. Import the repository into Vercel.
4. Framework: Vite.
5. Build command: npm run build.
6. Output directory: dist.
